## 📌 Overview

CricTalent is a mobile-based cricket talent discovery platform built to help local and emerging cricket players gain visibility and recognition.

Talented players often struggle to find opportunities because they lack a centralized platform to showcase their skills, performance statistics, achievements, and match videos.

CricTalent aims to bridge this gap by creating a digital ecosystem where players can present their cricketing abilities and coaches, scouts, and academies can discover promising talent.

## 🎯 Problem Statement

Many talented cricket players at local and grassroots levels remain undiscovered due to:

- Limited exposure to professional coaches and scouts.
- Lack of a centralized player portfolio.
- Difficulty showcasing match performances and statistics.
- Limited access to cricket academies and opportunities.
- Traditional and disconnected talent identification methods.

## 💡 Our Solution

CricTalent provides a centralized platform where:

- Players can create professional cricket profiles.
- Players can showcase batting and bowling statistics.
- Performance videos and achievements can be presented.
- Coaches and scouts can discover and evaluate players.
- Academies can explore potential cricketing talent.

## ⚡ Getting Started

### Prerequisites

- Node.js
- npm
- Git
- VS Code
- Expo Go or Android Emulator

### 1. Clone Repository

```bash
git clone https://github.com/YOUR-USERNAME/crictalent-mobile.git
```

### 2. Navigate to Project

```bash
cd crictalent-mobile
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npx expo start
```

### 5. Run with Clean Cache

```bash
npx expo start --clear
```
